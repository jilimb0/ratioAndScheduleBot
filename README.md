# 🤖 Ratio & Schedule Bot — Управление временем и балансом жизни

Telegram-бот для персонального тайм-менеджмента, отслеживания привычек, напоминаний и анализа соотношения работы и отдыха (Work / Rest Ratio).

## 🔧 Функциональность

- ⏰ **Персональные расписания и привычки**: управление через `/tasks`, `/addtask`, `/deltask`
- ⚖️ **Анализ соотношения времени (Work/Rest Ratio)**: расчет баланса, Life Balance Score (0–100) и текстовые прогресс-бары сфер жизни
- ⏱ **Умные инлайн-кнопки**: отметка выполнения ✅, откладывание на 15 мин (Snooze), пропуск (Skip)
- 🌅 **Утренний брифинг**: план на день в 08:00 по локальному времени пользователя
- 🌐 **Персональные часовые пояса**: настройка через `/timezone`
- 📱 **Telegram WebApp**: интерактивный таймлайн для визуального планирования дня
- ⭐ **Монетизация**: встроенная Pro-подписка за Telegram Stars (`/pro`)
- 🚀 **Виральный шеринг**: карточка продуктивности со стриком для сторис и каналов (`/share`)
- 💾 **SQLite база данных**: схема с персистентностью пользователей, задач, транзакций и стриков

## 🚀 Быстрый старт

### 1. Создание бота

1. Перейдите к [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Введите имя бота (например: `My Schedule Bot`)
4. Введите username бота (например: `my_schedule_bot`)
5. Скопируйте токен бота

### 2. Локальная установка

```bash
# Клонируйте репозиторий
git clone <your-repo-url>
cd telegram_bot

# Включите corepack (для pnpm) и установите зависимости
corepack enable
pnpm install

# Настройте переменные окружения
cp .env.example .env
# Отредактируйте .env файл и добавьте ваш BOT_TOKEN
```

### 3. Запуск локально

```bash
# WebApp dev-сервер
pnpm dev

# Проверка типов, линтер и тесты
pnpm type-check
pnpm check
pnpm test

# Production-сборка и запуск
pnpm build
node dist/worker.js
```

## 🌐 Развертывание на Render.com

### Пошаговая инструкция:

1. **Подготовка репозитория**:
   - Загрузите код на GitHub
   - Убедитесь, что все файлы на месте

2. **Создание сервиса на Render**:
   - Перейдите на [render.com](https://render.com)
   - Нажмите "New" → "Web Service"
   - Подключите ваш GitHub репозиторий
   - Настройте параметры:
     - **Name**: `telegram-schedule-bot`
     - **Environment**: `Node` (или Docker с `Dockerfile`)
     - **Build Command**: `corepack enable && pnpm install --frozen-lockfile && pnpm build`
     - **Start Command**: `node dist/worker.js`

3. **Настройка переменных окружения**:
   - В разделе "Environment" добавьте:
     - `BOT_TOKEN` = ваш токен от BotFather
     - `TIMEZONE` = ваш часовой пояс (например, `Europe/Moscow`)

4. **Деплой**:
   - Нажмите "Create Web Service"
   - Ожидайте завершения деплоя (5-10 минут)

Чтобы изменить расписание, отредактируйте файл `src/config.ts`:

```ts

  {
    id: 'morning_workout',
    time: '08:15', // Время в формате (час:минута)
    message: '🏃‍♂️ Время утренней тренировки!',
    buttonText: 'Тренировка выполнена ✅',
    category: 'health',
    durationMinutes: 45,
  },
  // Добавьте новые задачи или измените существующие
];
```

## 🐛 Решение проблем

### Бот не отвечает
- Проверьте правильность токена в `.env`
- Убедитесь, что бот запущен
- Проверьте логи на наличие ошибок

### Напоминания не приходят
- Убедитесь, что пользователь запустил бота командой `/start`
- Проверьте настройки часового пояса
- Проверьте, работает ли планировщик (логи)

### Ошибки базы данных
- Убедитесь, что SQLite поддерживается на платформе
- Проверьте права доступа к файлам
- При необходимости удалите `bot_data.db` для пересоздания
