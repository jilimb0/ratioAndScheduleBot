# ratioAndScheduleBot — План развития бота тайм-менеджмента

> **Мировой бенчмарк:** Reclaim.ai / Motion ($100M+ Val)  
> **Суть продукта:** Telegram-бот для управления распорядком дня, трекинга задач и напоминаний по расписанию.  
> **Текущий статус:** Чистый Python 3.9+, 25 юнит-тестов, dynamic APScheduler, SQLite с миграциями, Telegram Stars, Telegram WebApp.

---

## 1. Технический бэклог доработок (Technical Debt & Features)

- [x] **Поддержка повторяющихся расписаний и привычек**
  - Таблица `user_schedules` с категориями (`work`, `rest`, `health`, `study`, `routine`), длительностью в минутах и днями недели (`days_of_week`).
  - Команды `/tasks`, `/addtask <Имя> <HH:MM> [категория] [длительность]`, `/deltask <ключ>`.
  - Динамическая поддержка персональных часовых поясов пользователей (`/timezone`).
- [x] **Аналитика соотношения работы и отдыха за неделю в виде графика**
  - Модуль `get_ratio_analytics()` в `database.py`.
  - Команда `/ratio` (или кнопка «⚖️ Баланс (Ratio)»): подсчет Work/Rest Ratio, Life Balance Score (0–100), текстовые прогресс-бары распределения по сферам и персональные рекомендации по восстановлению.
- [x] **Интеграция с Telegram WebApp для визуального редактирования дня**
  - Готовый адаптивный Telegram Mini App (`webapp/index.html`) с поддержкой Telegram Theme Colors и WebApp SDK.
  - Встроенная раздача в `main.py` по маршруту `/webapp`.
  - Прием данных из WebApp в боте через `webapp_data_handler` (`filters.StatusUpdate.WEB_APP_DATA`).
